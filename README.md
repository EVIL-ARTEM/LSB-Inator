LSB-Inator

Консольная программа для скрытой передачи сообщений: текст шифруется алгоритмом RC4 и прячется в младшие биты пикселей PNG-изображения. Картинка при этом визуально не меняется.

Курсовая работа по дисциплине «Программирование», НГТУ, кафедра защиты информации. Автор: Мерзликин Артём, группа АБс-524.

Возможности
регистрация и вход пользователей; пароли хранятся только в виде хэша FNV-1a с солью из логина;
проверка пароля: не короче 8 символов, обязательно цифры и буквы; не более 3 попыток входа;
встраивание сообщения в PNG и извлечение его обратно;
шифрование сообщения RC4 перед встраиванием;
псевдослучайный порядок записи битов по ключу стеганографии — без ключа сообщение невозможно найти;
заголовок с длиной сообщения и контрольной суммой — повреждённые данные и неверный ключ обнаруживаются;
ключи вводятся с клавиатуры, читаются из файла или генерируются с сохранением в файл;
сообщение вводится с клавиатуры или читается из файла;
защита от некорректного ввода во всех меню.
Сборка

Нужен компилятор с поддержкой C++17.

bash
make

Под Windows — через MinGW или MSYS2, той же командой.

Запуск
bash
./LSB-inator

При первом запуске зарегистрируйте пользователя (пункт 2), затем войдите (пункт 1).

Тесты модулей
bash
make test_fileio && ./test_fileio
make test_rc4    && ./test_rc4
make test_image  && ./test_image
make test_lsb    && ./test_lsb
make test_auth   && rm -f users.dat && ./test_auth

RC4 проверяется на опубликованном тестовом векторе: ключ Key, текст Plaintext → BB F3 16 E8 D9 40 AF 0A D3.

Структура
Модуль	Назначение
Main_inator.cpp	точка входа: настройка консоли, вход и регистрация
menu	меню и сценарии встраивания и извлечения
auth	регистрация и проверка пользователей
fileio	чтение и запись файлов в бинарном режиме
rc4	шифрование RC4 и генерация ключей
image	загрузка и сохранение PNG
lsb	встраивание и извлечение битов, генератор позиций
lodepng	сторонняя библиотека для работы с PNG (lodepng)
Ограничения
поддерживается только PNG: сжатие с потерями, как в JPEG, разрушает младшие биты;
RC4 и FNV-1a выбраны в учебных целях; для реальной защиты данных нужны современные алгоритмы, например AES-GCM и Argon2.
